### Paso 1: Instala MariaDB desde el [sitio web](https://mariadb.org/download/) oficial

<img
  src="/images/windows/mariadb/sqlwindowslanding.jpg"
  alt="Página de instalación de MariaDB para Windows"
/>

### Paso 2: Configura MariaDB

1. Haz clic en el archivo de instalación descargado y ejecútalo.

<img
  src="/images/windows/mariadb/mysqlinstall.jpg"
  alt="Archivo de instalación de MariaDB para Windows"
/>

2. Sigue las indicaciones de instalación y selecciona las opciones adecuadas para tu servidor.

<img 
  src="/images/windows/mariadb/step2.jpg"
  alt="Configuración de MariaDB en Windows"
/>

3. Durante la configuración, se te pedirá que configures un usuario root y una contraseña. Asegúrate de recordar esta información, ya que la necesitarás para acceder a la base de datos.

<img
  src="/images/windows/mariadb/step3.jpg"
  alt="Configuración del usuario root de MariaDB en Windows"
/>

4. Cuando termines la configuración, haz clic en "Finish" para completar la instalación.

<Check>
**¡Felicidades!** Has configurado MariaDB correctamente en tu servidor Windows. Ya puedes empezar a usarlo para gestionar tus bases de datos.
</Check>
